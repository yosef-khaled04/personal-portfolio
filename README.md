# Personal Portfolio Website

The first version of my personal portfolio website, built with **HTML5 only** as part of the **Web Programming Basics** course (Assignment 01: Structuring Content with HTML).

The website introduces me, presents my skills, showcases my projects, and provides ways to contact me.

## Sections

- **Header & Navigation**: name, tagline, and links to all sections
- **Introduction**: profile picture and a short introduction
- **About Me**: background, interests, career objectives, and what I am currently learning
- **Skills**: grouped into Programming Languages, Web Technologies, Tools, and Soft Skills
- **Projects**: Recipe Book, easyCcalculator, and Kitabi
- **Education**: educational background in an HTML table
- **Contact**: a contact form, plus my email and social links
- **Footer**: copyright notice, quick links, and social links

## HTML Concepts Used

- HTML5 document structure (`<!DOCTYPE html>`, `head`, `body`, `meta charset`, `title`)
- Semantic elements: `header`, `nav`, `main`, `section`, `article`, `footer`
- Headings in a logical hierarchy (`h1` → `h2` → `h3`) and paragraphs
- Internal, relative, and absolute links
- Images with meaningful `alt` text
- Unordered lists
- Tables (`caption`, `thead`, `tbody`, `th`, `td`)
- Forms with labels and different input types (`text`, `email`, `textarea`, `button`)

> No CSS or JavaScript is used in this version, as required by the assignment.
